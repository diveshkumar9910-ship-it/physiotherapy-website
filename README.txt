# Dr. Sanjeev Pal — Premium Physiotherapy Website

## Run
1. Open this folder in VS Code.
2. Put the supplied/source images inside `assets/` using these filenames:
   - sanjeevpal.png
   - sanjeevpal.jpeg
   - sanjeev-2.jpeg
   - sanjeev-3.jpeg
   - sanjeev-4.jpeg
   - sanjeev-6.jpeg
   - sanjeev-7.jpeg
3. Open `index.html` with Live Server.
